# MMVII Documentation

**MicMac V2 (MMVII)** is a free, open-source photogrammetry suite developed at [IGN](https://www.ign.fr/) (French Mapping Agency). It is the second generation of [MicMac](https://github.com/micmacIGN/micmac), redesigned for long-term maintainability and external contributions.

## What is MMVII?

MMVII provides a command-line toolchain for:

- **Image orientation** — relative and absolute pose estimation
- **Dense matching** — stereo and multi-view depth reconstruction
- **Bundle adjustment** — large-scale photogrammetric block adjustment
- **Point cloud processing** — filtering, meshing, radiometry
- **Topometric processing** — integration of topo and photogrammetric measurements
