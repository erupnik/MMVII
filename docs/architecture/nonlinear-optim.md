# Non-Linear Optimisation

MMVII provides a Gauss-Newton solver for non-linear least-squares problems. This page
describes the class interfaces and how to use them. It is targeted at developers adding
new optimisation problems to MMVII.

!!! note "Prerequisites"
    Familiarity with least squares, linearisation, Gauss-Newton, and Schur complement
    is assumed. The [symbolic derivation](symbolic-derivation.md) page describes how
    to compute the required Jacobians.

---

## Problem formulation

Minimise:

$$
F(X) = \sum_{j=1}^{M} w_j \, f_j(X)^2, \quad X \in \mathbb{R}^n
$$

where:

- $X$ is the vector of unknowns
- $f_j$ are differentiable residual functions
- $w_j$ are weights
- an initial estimate $X_0$ close to the minimum is available

At each Gauss-Newton iteration, the $f_j$ are linearised around the current estimate $\tilde{X}$
and the resulting linear least-squares system is solved.

---

## Running example — 2D triangulation

The documentation uses a 2D point network as a running example: given a set of points
$P_1, \ldots, P_n \in \mathbb{R}^2$ and measurements of pairwise distances $d_{ij}$,
recover the point coordinates that minimise:

$$
D(X) = \sum_{j=1}^{M} \left(\frac{d(P_i, P_j)}{d_{ij}} - 1\right)^2
$$

Points $A=(0,0)$, $B=(0,1)$ are fixed to remove the gauge freedom (translation + rotation).

This example is fully implemented in `src/TutoBenchTrianguRSNL/` and serves as the
primary tutorial. **Read that code alongside this page.**

---

## Schur complement

For large problems where some unknowns are not of primary interest (e.g. 3D tie points
in bundle adjustment), the Schur complement efficiently eliminates them from the system
without affecting the solution for the remaining unknowns.

**Example:** bundle adjustment with 1 000 cameras and 1 000 000 points.
Without Schur: solve a $3\,003\,000$-unknown system.
With Schur: eliminate the $3\,000\,000$ point coordinates → solve a $6\,000$-unknown system.

In the 2D triangulation toy example, Schur is activated artificially by designating
the points on column $x=1$ as temporary (to be eliminated).

## Key class — `cResolSysNonLinear`

The main user-facing class is `cResolSysNonLinear`, declared in `include/MMVII_SysSurR.h`.

```cpp
// Instantiate the solver (DimUnknown = dimension of one unknown block)
cResolSysNonLinear<tREAL8> aSys(eModeSSR::eSSR_LsqNormEq, aNbUnknowns);
```

### Adding an observation

For each residual $f_j$, push the linearised equation into the system:

```cpp
// aVals[0]     = value of f_j at current X
// aVals[1..N]  = partial derivatives df_j/dX_k
// aVIndices    = indices of unknowns involved in f_j
// aWeight      = w_j
aSys.CalcAndAddObs(aCalc, aVIndices, aVObs, aWeight);
```

The calculator `aCalc` is generated by the [symbolic derivation](symbolic-derivation.md) system.

### Fixing unknowns (gauge constraints)

```cpp
// Fix unknown at index aIdx to value aVal with weight aW
aSys.AddEqFixVar(aIdx, aVal, aW);
```

### Solving and updating

```cpp
// Solve the system and get the update vector ΔX
auto aDeltaX = aSys.SolveUpdateReset();

// Apply the update to your current estimate
for (int aK = 0; aK < nPoints; aK++)
    mPoints[aK] += cPt2dr(aDeltaX[2*aK], aDeltaX[2*aK+1]);
```

`SolveUpdateReset` solves, returns $\Delta X$, and resets the accumulator for the next iteration.

### Schur complement usage

Declare which unknowns are "temporary" (to be Schur-eliminated) when building the system.
The interface is described in `include/MMVII_SysSurR.h` — see `SetFrozenFromPat` and related methods.

## Computing residuals and Jacobians

Residuals and their Jacobians are computed by **generated code** produced by the
[symbolic derivation](symbolic-derivation.md) system. The generated calculator
(e.g. `cDist2DConsVDer`) evaluates $f_j$ and all $\partial f_j / \partial X_k$
in a single vectorised loop.

```cpp
// Create calculator (generated class)
cDist2DConsVDer aCalc;

// Compute: fills value + Jacobian for a batch of observations
aCalc.SetCurParams(aVObs);
aCalc.CalcBatch(aVUnkVals, aVRes);
```
